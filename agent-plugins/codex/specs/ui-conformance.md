# 资源中心 UI 逐页对照表

基线：已确认的 71 张 SVG 与文字 spec；修正版本：`0.1.0-dev.6`。图稿文件保持不变。
本表逐项对照页面结构、信息顺序、操作所在位置和状态切换，不以工具调用成功代替视觉验收。
本地浏览器验证使用实际 UI 与核心、合成服务响应。真实环境配置、脚本、截图和操作轨迹均保存在仓库外。

## 结论与修正范围

此前实现有跨页面的结构性偏差：通用表单布局被用于列表筛选，本地资源名称、描述和动作拆散，
MCP 分区仅在工具页出现，版本操作缺少选中版本区域，部分结果页依赖零散按钮。
本轮统一子页标题、详情分区、状态摘要和操作栏，并修复嵌套返回与确认页重复返回。
源码对应关系覆盖全部 71 帧；下表明确区分实际交互回归与仅完成源码对照的分支。

## dev.7 后续修正

按新增反馈，发现资源改为默认查询第一页，关键词可选；清空搜索和类型单独筛选可用，分页沿用已提交条件。
加载更多与列表分割线间隔 20 CSS px；统一下拉箭头区域、表单内边距和窄屏搜索排列。
浏览器检查覆盖发现/安装目标、设置认证/目录编辑及服务认证；320 深色与宽屏浅色均检查控件边距。
本节不改变下表其他分支的验证层级，完整内嵌验收仍待完成。
