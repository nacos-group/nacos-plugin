# 资源中心 UI 场景与交互图册

**状态：当前 SVG 版本为已选定设计基线，实现正在逐页修正；逐帧结论见 [UI 对照表](ui-conformance.md)，实际应用验收见 TODO 与测试矩阵。** 本图册落实[Codex UI 规范](resource-center-ui-spec.md)
及[通用操作与状态规范](../../specs/resource-center-interaction-spec.md)。后续适配可复用文字契约，
按所在 Agent 应用调整 CSS；本图册的具体颜色、尺寸和组件只作为 Codex 设计参考。
一张图只显示一个界面状态，不再把菜单样本、操作步骤和多种结果拼成同一产品页面。
所有资源、地址、路径与身份均为通用示例，不是本地测试环境或操作记录。

## 1. 先明确哪些是真实页面结构

| 用户动作 | 实际呈现 | 保留的上下文 |
| --- | --- | --- |
| 点击资源行的 `⋯` | 按钮旁的小浮层，不打开独立页面 | 资源列表、选中详情、筛选与滚动保持原样 |
| 点击 Skill 的检查更新 | 在当前详情区显示变更；冲突仅在检查发现时出现 | 左侧仍是原已接入列表，返回回到技能详情 |
| 点击卸载或解除接入 | 说明对象与影响的一次确认弹窗 | 原列表留在背景；取消恢复，成功后更新列表并展示结果 |
| 配置 MCP / 接入 Agent | 当前详情区显示一张配置表单 | 保存后该区域切换为结果；发送任务需要后续单独操作 |
| 点击我的资源的 `⋯` | 原资源行旁的维护菜单 | 权限不足显示在版本动作区，不与菜单并排 |
| 上传 | 带返回入口的独立子页，内部逐步前进 | 不同时显示编辑表单、确认、成功和失败 |
| 打开设置 | 隐藏三个主标签，顶部保留返回、设置标题和连接摘要，正文仅有设置分组与当前内容 | 返回恢复原工作区；取消编辑仅回设置摘要，内部状态切换不改变返回来源 |

因此，更新、冲突、卸载不是一个三栏页面；MCP 与 Agent 的解除确认也不同时出现。
接入表单、保存结果、服务诊断是连续或按条件进入的状态，不是页面上并排的小块。

## 2. 如何阅读与点击

打开[可点击图册](assets/ui/index.html)，建议从“已接入 · 资源列表”开始直接操作图内控件。
左侧按工作流分组的是**图册目录**，右侧“设计说明 / 设计分支”也只属于图册，不进入产品。
画面中的工作区、详情、浮层与确认弹窗才是目标 UI。

菜单图保留当前页面背景；点击空白或 Escape 关闭。选择菜单项后只出现相应步骤。
危险确认点取消恢复原工作区（列表或详情），确认后才进入结果。窄屏使用同一流程的单列详情子页。
场景编号与浏览器 hash 只是设计帧定位，不代表产品需要为每个状态创建路由。

图册是离线固定示例，不连接服务、不读取本机业务文件、不执行真实操作。输入内容仍为
示例；点击查询、保存等会进入一条预设设计路径，不能解读为服务一定返回该结果。
失败、冲突等通过画面外的“设计分支”查看，不在产品里增加模拟按钮。

共有 71 张独立状态 SVG。数量来自流程拆分，不是 71 个主页面；三项主导航仍为
**已接入 / 发现资源 / 我的资源**。MCP 的工具与连接、Agent 的能力与任务是类型专属详情。
我的资源当前仅管理 Skill，本地技能与设置是子页。

## 3. 主要点击路径

| 路径 | 进入与变化 | 返回 / 异常规则 |
| --- | --- | --- |
| 已接入 → 更多菜单 | 01 → Skill 02 / MCP 21 / Agent 22，仅浮层出现 | 点外部 / Escape 回到原画面；菜单不切换资源选择 |
| 检查更新 | 02 → 03 变更确认 → 24 更新结果 | 检测到修改才进入 23；处理后重新检查；卸载不在此流程中 |
| 卸载技能 | 02 → 25 确认弹窗 → 26 卸载结果 | 取消恢复原画面；本地修改阻止执行，远端资源保留 |
| 服务解除接入 | MCP 21 → 20 → 43；Agent 22 → 42 → 44 | 分别说明本地影响；Agent 解除不会取消已发任务 |
| 搜索安装 | 04 资源详情 → 40 目标 → 41 变更 → 05 结果 | 目标或版本改变须重新规划；搜索列表保持原位 |
| 我的资源菜单 | 06 → 17 浮层 → 版本详情或本地技能 | 没有一张“菜单和权限并排”的页面 |
| 版本提交与发布 | 06 → 07 提交确认 → 35 审核中 → 56 审核通过 → 55 发布确认 → 36 已发布 | 无匹配流程可能提交后直接发布；37 权限不足是版本状态分支 |
| MCP 连接 | 已接入：09 → 27 → 28 → 08；搜索中：63 概览 → 64 配置 → 65 保存 → 66 诊断 → 67 工具 | 保存、诊断、应用加载与实际调用独立；不自动串成成功 |
| Agent 接入 | 53 能力 → 18 表单 → 29 接入结果 → 10 任务输入 | 失败走 30，保留输入；已接入的设置走 69 → 70，接入时不发送任务 |
| Agent 任务 | 10 输入 → 11 运行 → 31 回复；11 请求取消 → 32 待确认 → 33 已取消 | 34 发送结果未知无任务引用，不显示可用的查询/取消，不自动重发 |
| 上传草稿 | 12 本地技能 → 13 文件 → 19 保存确认 → 39 结果 | 预检会传输文件，但尚未保存；保存结果核验后才展示确切版本 |
| 上传冲突 | 13 的预检发现冲突 → 38 → 分别确认绑定/覆盖 → 57 → 60 覆盖确认 | 两个选择独立；58/59 为仅选择一项；没有可靠冲突信息不能覆盖 |
| 设置 | 任意工作区的设置入口 → 14 摘要 → 45 编辑 → 46 已保存；另行检查后显示检查结果 | 四个状态都隐藏主标签；顶部返回原工作区，取消编辑回 14；47 失败保留输入 |

以上路径展示典型分支。图册通过设置入口进入时记录原工作区，编辑、保存、检查后返回该来源；
从图册目录直接打开设置或单独打开 SVG 时，返回使用“已接入”的示例起点。
其他固定示例的返回链接不替代真实上下文恢复；真实实现须按发起位置恢复原上下文，
例如从发现资源进入服务配置，就在原搜索详情内完成，不应自动切换已接入。
页面重开、身份变化和计划失效仍按主规范处理，不从固定示例中推断数据可复用。

## 6. 状态与实施边界

同一时刻只呈现一个操作步骤。更新冲突保留本地文件；上传冲突先确认对象和权限；未知结果
先核对已有操作，不用再次写入探测结果。审核完成须显示真实结论，不等于发布成功。

MCP 工具发现、Codex 加载与业务调用分别记录。Agent 接入、任务、取消也分别反馈；取消
确认前不能显示已停止，取消不撤销先前远端效果。任务摘要和历史必须来自可靠核心接口。

只管理当前上下文中受管资源。上传与发布明确目标、确切版本、文件变化及可见性，凭据仅
引用本机环境变量。这里的“私有（已核验）”等示例结论不能用于替代真实结果核验。

设计冻结后的实现状态见 [TODO](TODO.md) 与[测试矩阵](test-matrix.md)，不由图稿替代验收。实现以
[通用 UI 规范](../../specs/resource-center-ui-spec.md)、[Codex 具体规格](resource-center-ui-spec.md)、
[通用操作与状态](../../specs/resource-center-interaction-spec.md)及此图册共同约束。
运行验收须实际检查浮层开关、焦点、返回、原位结果、条件冲突与重复提交；
不能以图册跳转通过替代真实插件功能验收。
