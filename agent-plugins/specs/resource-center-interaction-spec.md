# 资源中心通用操作与状态规范

**状态：设计基线，尚不代表各插件已实现。** 本文将已选定 SVG 方案中的操作规则独立为
跨 Agent 应用的文字契约。配合[通用 UI 规范](resource-center-ui-spec.md)阅读：
UI 规范负责信息架构、呈现原则和主题适配，本文负责入口、状态转换、执行影响、返回和异常。
具体 API、CSS、组件库和像素值由 `agent-plugins/<agent>/specs/` 定义。

本文中的“必须”是实现与验收要求；“可以”是允许的适配选择；示例资源和图稿分支不是
服务端能力声明。资源身份、授权、计划和生命周期仍分别以
[治理](connection-governance-spec.md)、[装配](assembly-sync-spec.md)、
[资源管理](resource-management-spec.md)和[Agent 互联](agent-interoperability-spec.md)为准。
文字与图稿不一致时应修订并保持一致，不得凭一张图新增权限、接口或执行行为。

## 1. 操作承载与共享状态

### 1.1 界面区域

| 区域 | 用户看到什么 | 使用限制 |
| --- | --- | --- |
| 主工作区 | 已接入、发现资源、我的资源之一及其列表 | 三者是业务视图，可使用标签或应用原生导航呈现；资源类型只是筛选，不增加三个类型主页面。 |
| 详情区 | 选中资源的说明、专属分区及当前操作 | 宽容器与列表并排；窄容器进入带返回的单列详情。 |
| 详情中的步骤 | 输入、变更确认、执行、冲突或结果之一 | 前进一步替换当前内容；不把整个流程缩成一排卡片，不自动切换主视图。 |
| 更多浮层 | 当前行的次要动作 | 锚定 `⋯`，不打开完整页面，不替换背景列表或详情。 |
| 危险动作确认 | 对象、范围、影响、取消和最终动作 | 一次模态确认；使用应用可支持的对话框或等价模态容器，不叠第二次通用确认。 |
| 独立子页 | 设置、本地技能、上传、待处理操作 | 有标题与返回入口；设置隐藏三主导航，其他子页不因此强制隐藏导航。 |

同一时刻只显示一个当前步骤或结果，只打开一个菜单或确认层。浮层关闭后回到原画面，
步骤返回后恢复上一步；这两类动作不能混同。确认层背后的工作区保留但不可交互。
窄屏改变排列与承载方式，不改变授权、执行次数和结果含义。

### 1.2 上下文与返回

一次操作至少关联以下逻辑信息；这些名称不是强制代码类型或新的持久化 schema。

| 信息 | 内容与用途 |
| --- | --- |
| 来源工作区 | 主视图、已提交搜索/筛选、已加载页、选中引用、详情分区、滚动位置和触发控件。 |
| 授权上下文 | 连接、namespace、服务身份、项目/作用域与目标；用于检查数据是否仍可使用。 |
| 当前步骤 | 操作种类、输入草稿、解析后的版本/端点、必要确认及计划基线。 |
| 已执行操作 | 操作 ID、真实阶段、最近核验结果；有有效任务引用时另存其关联。 |

打开菜单不改来源；进入子页只记录一次来源，子页中的编辑、保存和诊断不能覆盖它。
“返回”恢复上一步，“返回资源中心”恢复来源工作区，“查看已接入/我的资源”是用户主动
切换目的地。返回不会再次执行操作。原触发项仍存在时恢复焦点，已卸载等导致它消失时
把焦点放到相邻资源或结果标题，不落到隐藏控件。

以上恢复仅在授权上下文仍有效时成立。身份、连接、namespace 或作用域变化后清除旧范围
数据、选择和待执行计划；可保留安全的目的视图，但须重新读取并说明变化，不能恢复旧授权数据。
输入草稿不等于已保存配置；默认不把私有查询、任务正文和草稿写入浏览器持久存储。

### 1.3 共同的操作规则

| 阶段 | 展示与可用操作 | 执行边界 |
| --- | --- | --- |
| 读取/准备 | 局部进度，保留已有列表；允许返回 | 不因打开详情或菜单而写入。 |
| 输入/确认 | 必需字段、确切对象、目标、变化、一个主动作 | 修改输入使旧计划失效；缺少权威信息时禁止依赖它的写入。 |
| 执行中 | 当前阶段、执行对象；禁用重复或冲突写入 | 关闭或返回不表示撤销；没有取消契约就不提供取消执行。 |
| 完成 | 以实际动作命名结果，更新原行，提供下一步 | 只根据核验结果显示完成，不自动执行下一项动作。 |
| 冲突/已知失败 | 原因、受影响对象和修正入口，保留输入 | 冲突解决后重新规划；仅对已确认可安全重试的动作开放重试。 |
| 未知/部分完成 | 持续可见的核对入口或逐项结果 | 不把超时当作失败重发，不重放已成功项。 |

确认步骤的最终动作已经构成一次明确提交，不再补一个“确定吗”。未知结果不能只用自动
消失的提示表示。保存配置、写入文件、应用加载、连接诊断、业务调用是不同事实，独立反馈。

## 2. UIX-01 主视图、列表与类型详情

入口按是否配置、是否有接入记录选择设置引导、发现资源或已接入；同一有效上下文可恢复
上次工作区。首次进入发现视图自动读取当前身份可见资源的第一页，空关键词表示全部；
其他视图打开不触发发现查询。不自动扫描、上传或发送任务。失败后的重试及后续分页由用户触发。

点击名称打开详情；点击行主动作进入该动作；点击行内控件不同时触发行选择。
每行最多一个可见主要动作与一个更多菜单。搜索提交、筛选、分页、无结果与读取失败
按通用 UI 规范区分；查询变化使旧分页失效，迟到响应不能覆盖新查询。

| 对象与上下文 | 详情分区 | 不能混用的含义 |
| --- | --- | --- |
| 已接入 Skill | 说明、来源与文件、安装/加载状态、更新 | 本地安装不等于应用已经加载。 |
| MCP | 概览、工具、连接 | 已发现工具不等于应用已加载或已调用。 |
| 远端 Agent | 能力、发起任务、当前任务 | 服务绑定、任务接受、任务完成分别反馈。 |
| 我的资源 Skill | 维护者概览、版本与发布 | 不套用安装/卸载详情；所有权由服务身份核验。 |

分区名称可以随应用语言与原生组件调整，但其内容和动作边界不变。没有数据或能力的分区
不保留伪空页；已有功能暂时失败时保留入口和原因，不能伪装成无资源。

## 3. UIX-02 行内更多菜单

点击 `⋯` 只打开当前行旁的菜单，不刷新列表、不选择另一资源、不清空详情。
再次点击、点击外部或 Escape 关闭并恢复触发焦点；选择项后关闭菜单并进入对应流程。
键盘可打开、移动和执行菜单项。禁用项显示可读原因；未交付的能力不显示为可执行项。

| 上下文 | 菜单项 | 点击结果与前置条件 |
| --- | --- | --- |
| 已接入 Skill | 查看详情 | UIX-01：当前安装记录对应的版本、来源和完整路径。 |
| 已接入 Skill | 检查文件与访问 | UIX-04：只核验文件和远端读取。 |
| 已接入 Skill | 检查更新 / 查看变更 | UIX-04：解析版本并比较基线；没有检测结果时文案为检查更新。 |
| 已接入 Skill | 卸载技能… | UIX-05：核对受管文件、目录和本地修改。 |
| 已接入 MCP | 查看工具 | UIX-06：展示最近工具发现结果，区分未读、失败和零工具。 |
| 已接入 MCP | 连接诊断 | UIX-06：诊断选定服务，不调用业务工具或自动改配置。 |
| 已接入 MCP | 更新连接设置… | UIX-06：进入端点、独立凭据引用与配置影响的当前步骤。 |
| 已接入 MCP | 解除接入… | UIX-05：确认移除本插件管理的本地连接。 |
| 已接入 Agent | 查看能力 / 发起任务… | 分别进入 UIX-07 能力说明与 UIX-08 任务输入。 |
| 已接入 Agent | 查看当前任务 | UIX-08：仅有效上下文和任务引用可查询；无引用禁用并解释。 |
| 已接入 Agent | 更新连接设置… | UIX-07：编辑现有服务绑定，不发送任务。 |
| 已接入 Agent | 解除接入… | UIX-05：确认移除绑定，不取消活动任务。 |
| 我的资源 Skill | 查看概览 / 查看版本与发布 | UIX-09：进入维护者详情，先选确切版本。 |
| 我的资源 Skill | 从本地更新草稿… | UIX-10/11：选择本地来源，再核对文件与远端对象。 |

卸载和解除放在菜单末尾，以分隔和危险文案区分。提交/发布必须先选版本，不作为资源行
的一键菜单动作。所有操作仍由核心检查权限和基线；菜单可见或启用不构成授权。

## 4. UIX-03 Skill 发现与安装

入口是发现资源中的详情或“安装技能”。选择步骤显示版本选择器、解析结果和合法目标；
只有一个合法目标时可以预选，执行前仍显示完整路径。没有版本枚举能力时不能虚构版本列表。

依次在同一详情区显示“选择目标 → 查看安装变更 → 安装确认 → 执行 → 结果”。
确认包括名称、来源、确切版本、完整目录和新增/修改/删除摘要；最终按钮为“安装技能”
或实际需要的“更新技能”。只有点击最终动作才应用计划，变更目标、版本或内容后重新规划。

返回确认前一步保留输入；缺少目录可进入设置，返回后重新生成计划。
完成后更新搜索结果行并留在当前详情，显示应用加载状态；用户可选择查看已接入或继续搜索。
失败保留目标与输入；冲突进入 UIX-04 的处理规则，未知结果按 UIX-14 核对。

## 5. UIX-04 Skill 检查、更新与冲突

“检查文件与访问”独立读取并展示检查结果，不写文件、不证明应用加载。
“检查更新”从受管安装的菜单或详情进入，解析目标版本和文件基线后在详情区展示差异。
当前操作对象是所选安装记录，不能把同名资源的其他目录一并更新。

无冲突时显示旧/新版本、路径与文件变化，用户点击“更新技能”后才执行。
检测到本地修改或其他基线冲突时，当前区替换为冲突说明，指出文件和原因，明确尚未执行；
不同时展示可用的更新按钮，不提供默认强制覆盖。用户处理差异后点击“重新检查更新”，
该动作只重新读取/规划。返回回到原技能详情，文件保持原样。

成功后当前区显示实际版本与加载要求，更新原安装行。卸载是 UIX-05 的另一条入口，
不能作为更新流程的固定下一步，也不能把更新、冲突、卸载并排展示。

## 6. UIX-05 Skill 卸载与服务解除接入

入口是所选受管记录的更多菜单。打开一次确认层，读取计划期间不得执行；计划可用后
展示名称、完整目标、实际移除范围和保留内容，提供“取消”及明确的最终动作。
默认焦点不落在危险按钮。未执行时取消或 Escape 关闭，恢复原列表或详情，不修改资源。

| 对象 | 确认影响 | 成功后的原位结果 |
| --- | --- | --- |
| Skill | 仅移除归属明确的受管文件；检测到本地修改则停止；不删除远端资源或其他技能。 | 关闭确认层，更新/移除对应安装行，显示卸载结果与应用加载限制。 |
| MCP | 仅移除受管连接配置，保留其他配置和远端服务。 | 关闭确认层，更新连接行，说明应用是否仍需刷新。 |
| Agent | 仅移除本地绑定；明确活动任务和远端服务不停止。 | 关闭确认层，更新绑定行；已知任务仍按原引用核对。 |

执行中禁用重复确认，不把关闭动作命名为取消执行。若允许关闭，操作仍可从记录核对；
失败或未知保留结果入口和原操作引用，不能重新弹确认并自动重试。
解除 Agent 绑定与 UIX-08 的请求取消分别执行；不增加“解除并停止全部任务”的隐式行为。

## 7. UIX-06 MCP 概览、连接与工具

发现资源和已接入均可进入 MCP 详情；全过程保留发起时的主视图与列表。
概览展示用途和已核验注册信息。连接步骤显示支持的协议、注册端点选择、独立凭据引用、
受管配置目标和将发生的修改；不提供任意地址覆盖，不复用 Nacos 管理凭据访问下游。

配置步骤可直接承载核对与最终保存，不要求再弹一个确认。保存成功在同一区域显示结果及
应用刷新要求；诊断是另一个显式动作。诊断读取选定服务和工具描述，不执行业务工具。
工具分区区分未读取、读取失败、真实零项和已发现工具，展示描述与输入摘要。

编辑或诊断失败保留输入/已有结果并说明新状态；端点或凭据引用改变使旧计划失效。
返回恢复上一步，保存不自动切到已接入。提供 UIX-13 的对话使用入口时仍须核实应用能力。

## 8. UIX-07 Agent 能力与接入

发现中的“查看能力”进入能力说明，再进入接入步骤；已接入中的“更新连接设置”编辑
已有绑定。输入步骤展示注册端点、协议及独立认证引用；字段根据实际认证方式出现，
不能把示例中的某一种认证固定为所有 Agent 的要求。

“确认接入”或“保存接入设置”只应用服务绑定，成功后同一区域显示结果与“发起任务”
下一步。失败替换当前步骤的反馈并保留输入，允许修正。该流程不发送任务，不写 MCP 配置，
不把接入成功解释为下游任务已经完成。返回恢复能力说明或进入前的绑定详情。

## 9. UIX-08 Agent 任务、结果与取消

从能力说明或已接入的“发起任务”进入输入步骤，同时展示接收对象/端点和将发送的文本。
点击“发送任务”才传送这些内容；不自动附带整个聊天、文件或其他资源。发送前返回保留
草稿或明确提示丢弃；发送后离开页面不取消任务。

| 观察到的状态 | 当前详情呈现 | 后续动作 |
| --- | --- | --- |
| 直接消息回复 | 可读回复及其来源，不伪造任务引用 | 可以返回能力说明；新任务是新的显式操作。 |
| 已接受且有任务引用 | 当前任务状态、可读输出和最近核验信息 | 按契约查询；可取消状态下提供“请求取消”。 |
| 请求取消已发送 | 等待远端确认，仍保留已知任务状态 | 查询同一任务；不显示已停止，不重复发取消请求。 |
| 已确认取消 | 展示实际终态，说明不撤销已产生的远端效果 | 返回详情或查看已有输出。 |
| 已完成/失败 | 协议终态、可读结果或原因 | 不用任务完成推断业务结论正确。 |
| 发送结果未知且无任务引用 | 保留输入与目标，持续展示核对说明 | 不开放无依据的查询/取消，不直接重发；进入 UIX-14。 |

请求取消在当前任务区操作，等待确认是远端状态，不是额外的弹窗步骤。
查询、取消与解除接入互不替代。没有可靠任务摘要接口时不虚构历史列表或重开恢复能力。

## 10. UIX-09 我的资源、版本与发布

进入时核验服务身份与所有权；未知身份、无权限、读取失败和真实空列表分别呈现。
行与详情可以同时显示已发布版本和草稿/审核版本，但一次操作只针对一个确切版本。
行菜单使用维护动作，不出现本地卸载；从本地更新草稿进入 UIX-10/11。

| 当前步骤/状态 | 当前区显示与动作 | 下一状态的依据 |
| --- | --- | --- |
| 版本选择 | 版本、可见性、审核摘要与允许的动作 | 服务端状态与真实权限。 |
| 提交确认 | 对象、版本、目标和可见性；最终按钮“提交版本” | 有匹配流程可能进入审核，无匹配流程可能直接上线。 |
| 审核中 | 最近已知进度及刷新入口 | 不允许重复提交；刷新仅查询。 |
| 审核完成 | 实际检查结论；满足普通发布条件时提供发布入口 | reviewed 不能单独证明已批准。 |
| 发布确认 | 确切版本及影响；最终按钮“发布版本” | 核验真实发布结果后显示已发布。 |
| 权限不足/失败/未知 | 原因、可继续的读取或核对入口 | 不提供跳过审核、强制发布或管理员替换。 |

提交/发布在详情中逐步替换，不把菜单、审核、确认与结果并排。
取消确认回到该版本详情；完成更新版本状态并留在原工作区，不自动发布下一个版本。

## 11. UIX-10 本地技能扫描、跟踪与忽略

从我的资源工具栏、设置中的相关入口或初始化完成页进入独立子页。
选择目录后点击扫描才读取；结果默认不选中资源，不因扫描或跟踪自动上传。
列表显示名称、目录、管理方式和可读状态，错误项保留原因。

选择后显示数量和已支持的批量跟踪/忽略动作；逐项显示成功、跳过和失败，不重放成功项。
上传按所选单项进入 UIX-11，不假定批量上传已交付。返回恢复进入前的工作区与位置；
重新扫描使旧候选选择和上传摘要失效。

## 12. UIX-11 文件预览、上传与草稿冲突

入口是所选本地 Skill 的上传/更新草稿动作。独立子页每次只展示文件预览、冲突处理、
保存确认或结果之一；返回保留上一步选择，输入变化使旧预检和确认失效。

| 步骤 | 必须可见的信息 | 用户动作与实际影响 |
| --- | --- | --- |
| 文件与目标预览 | 接收环境、namespace、资源、文件路径/大小、数量和总量 | “发送并预检”才传包；不能把传输隐藏在打开预览的行为中。 |
| 正常预检结果 | 新建/更新、实际目标版本、可见性、文件变化 | 在同一区域核对，尚未保存草稿。 |
| 冲突处理 | 已核验的同名资源、已有草稿及所需处理 | 同名绑定与覆盖草稿是独立选择，默认均不勾选；只要求当前冲突确实需要的选择。 |
| 重新预检 | 当前选择和将绑定/覆盖的对象 | 重新检查授权和基线，不凭旧冲突文字推断可覆盖。 |
| 保存/覆盖确认 | 确切草稿、对象、文件变化和可见性 | 条件满足才开放“保存草稿”，点击后执行一次，不再套通用确认。 |
| 保存完成 | 核验后的实际版本和可见性 | 提供“查看我的资源”或返回本地技能；不自动提交/发布。 |

只选了绑定不等于允许覆盖，反之亦然；缺少当前冲突所需选择时不能执行保存。
没有结构化冲突或可靠读取依据时停止该写入并说明缺口。结果未知保留操作引用，
按 UIX-14 核对，不重新上传探测是否成功；失败保留文件选择和目标。

## 13. UIX-12 设置与返回来源

问答、默认目录发现和对话预填遵循[初始化规范](onboarding-spec.md)，凭据字段与保存生命周期
遵循[凭据规范](credential-management-spec.md)。本节定义进入设置后的界面状态及返回。

设置是独立子页。摘要、编辑、保存完成、连接检查结果均隐藏三主导航及日常工具入口，
顶部只保留返回、设置标题和必要连接摘要。分组可随应用采用侧边列表或内容上方导航；
连接/身份、目录、操作范围和高级信息按需要展开。本地技能入口是跳转，不把扫描清单
嵌入设置表单；图稿展示的部分分组不表示可以省略必需配置。

| 动作 | 当前内容变化 | 返回与执行规则 |
| --- | --- | --- |
| 打开设置 | 已有配置显示摘要；首次连接进入必要的引导 | 记录原工作区，内部步骤不覆盖来源。 |
| 编辑连接 | 选择认证方式，再选择页面填写或环境变量 | 页面填写依赖已验证的安全输入与存储；配置仅保留引用。切换方式清空秘密与不适用的必填约束。 |
| 取消编辑 | 回到设置摘要 | 不保存；可保留非敏感草稿，清空尚未提交的秘密并明确提示。 |
| 保存配置 | 成功回到摘要并标记已保存、未检查；失败保留非敏感输入 | 清空秘密；不自动诊断、不宣称已经连通。对话初始化可在确认保存后按已有授权单独诊断；修改相关输入使旧计划失效。 |
| 检查连接 | 在摘要中更新实际检查结果和时间 | 失败保留已保存配置；消费读取成功不能证明管理写权限。 |
| 返回资源中心/原操作 | 恢复有效的来源工作区 | 受 §1.2 的上下文失效规则约束；原操作重新规划后才能执行。 |

从图册目录直接打开设置时可以使用示例返回起点；真实插件必须处理来源缺失，回到可靠
默认工作区，不能从静态图中的固定链接推断用户一定从已接入进入。

## 14. UIX-13 交给当前对话使用

入口是已准备资源的“在当前对话中使用”。具有有效对话和消息能力时，仅交接选定引用、
版本、目标和必要摘要，结果显示“已发送到当前对话”；这不等于应用已加载或业务执行成功。
Skill、MCP 使用该模式，Agent 任务发送仍按 UIX-08 独立处理。
已安装 Skill 详情将该入口作为主操作，检查文件、检查更新作为次要操作。
应用适配层应结合实际页面入口与协商能力判断；侧栏展开、全屏等布局变化不应使
已有会话的交接入口失效，也不能将布局变化当作获得会话权限的依据。

没有有效对话或该能力时提供“复制使用说明”；剪贴板不可用则显示可选文本。
不得创建新会话规避能力限制，也不自动发送私有文件或整页搜索结果。
返回原详情，保留来源和选择；消息发送失败时不显示已交接，能否重试须有明确结果依据。
发送中提供等待状态并防止重复提交；超时标记结果未确认，不自动重发。

## 15. UIX-14 待处理操作与恢复

入口是顶部待处理操作或未知/恢复状态的核对入口。只列当前有效上下文中有可靠记录的
未完成或未知操作，包含可读动作、对象、阶段和查看记录；不把它扩展为虚构的完整历史。
点击记录读取已有结果，不能重发原动作。

有完成证据才显示完成，有失败证据才显示失败；仍无结论时保留未知。
本地恢复必须说明范围和影响，由核心支持的恢复能力执行；不承诺撤回远端发布或取消未知任务。
返回保持来源工作区；重开时从核心读取事实，而非把图册中的预设结果当作恢复数据。

## 16. 适配与验收要求

各应用适配必须为 UIX-01–UIX-14 给出“支持 / 受限 / 不支持 / 待验证”、工具映射与
限制说明；通用流程存在不等于目标应用已支持。UI 不可用时保留已支持的对话/工具路径，
不伪造页面、剪贴板、主题变量或任务能力。

验收按入口、输入、前置条件、当前状态、执行影响、返回目标和异常逐项验证。
同一用例在宽窄、浅深色下应产生相同语义结果；可以使用不同原生控件与 CSS。
通用检查项见 [UI 验收清单](resource-center-ui-spec.md#12-通用验收清单)，
当前图稿映射见 [Codex 图册](../codex/specs/ui-storyboard.md#7-通用操作与图稿映射)。
初始化、凭据与目录另按 [ONB/CRED/DEF 场景](onboarding-acceptance-spec.md)验收。
实际应用验收与静态图册验证分开记录，私有环境配置和操作记录仍只保存在仓库外。
