# 初始化、凭据与默认值通用验收

本文为[初始化](onboarding-spec.md)与[凭据管理](credential-management-spec.md)提供可复用
场景编号。规则在对应规范维护，本文记录应检查什么，不记录某个产品已通过。
资源中心其他操作沿用 [UIX](resource-center-interaction-spec.md) 和
[通用 UI 验收 U01–U10](resource-center-ui-spec.md#12-通用验收清单)。

## 1. 初始化与交接

| 编号 | 验收场景 |
| --- | --- |
| ONB-01 | 区分未配置、工具不可用、执行位置不符；不以插件或工作流可见替代运行工具可用。 |
| ONB-02 | 只问缺项，保留已提供信息；单地址及独立管理配置分别覆盖。 |
| ONB-03 | 认证协议和凭据来源分别选择；无认证、页面和环境变量按能力出现；无安全能力不降级明文。 |
| ONB-04 | 打开设置与非敏感预填不写持久配置；用户提交后才确认保存；模型不输入或提交秘密。 |
| ONB-05 | 草稿冲突、另一窗口修改、迟到结果不会覆盖当前编辑或新配置；结果未知先重新读取。 |
| ONB-06 | 保存与诊断分离；对话按已有授权在确认保存后诊断，不用等待时长猜测完成。 |
| ONB-07 | 环境变量对实际插件进程可见；无页面环境能按声明的替代路径完成设置。 |
| ONB-08 | 初始化后可跳过盘点；扫描、上传、发布分别授权；返回保持有效来源与输入。 |

## 2. 凭据生命周期

| 编号 | 验收场景 |
| --- | --- |
| CRED-01 | 登录与 Token 的保存、替换、清除；普通字段修改不要求重新输入秘密。 |
| CRED-02 | 应用存储空间、连接、身份、目标与用途隔离；任意引用和跨目标复用被拒绝。 |
| CRED-03 | 权限拒绝、条目缺失、存储不可用分别反馈；配置引用存在不等于可读取。 |
| CRED-04 | 新条目与配置引用一致性、竞争拒绝、失败后持久状态核对、回滚和遗留清理重试。 |
| CRED-05 | 新进程、页面重开、对话重开和应用重启后分别验证；变更使旧缓存立即失效。 |
| CRED-06 | 合成秘密明文不进入普通工具记录/结果、模型上下文、配置、日志、浏览器持久存储和发布包。 |
| CRED-07 | 取消、离开、切换认证、失败及结果未知清除秘密；非敏感草稿可继续。 |
| CRED-08 | 目标变更与跨来源重定向不携带旧秘密；Nacos 与下游服务认证分别验证。 |
| CRED-09 | 采用信封方案时覆盖固定算法、公开向量、互通、篡改、重放、过期、长度限制及禁网页面。 |
| CRED-10 | 升级保留凭据；清理配置只清理归属条目，报告未清除项并保留本地 Skill。 |

## 3. 默认值与目录

| 编号 | 验收场景 |
| --- | --- |
| DEF-01 | 页面和对话使用同一适配器默认值；显示实际路径、用途及来源。 |
| DEF-02 | hostname/系统用户仅作本地建议；缺失时有后备，已有标识不随机器信息变化；多连接不混淆。 |
| DEF-03 | 不存在、不可读、无效、符号链接与越界目录分别处理；空扫描候选不阻塞连接。 |
| DEF-04 | 保留已有值和主动清空项；追加默认目录去重且保留自定义项、顺序与适配器上限。 |
| DEF-05 | 自定义预填、取消、保存与重开一致；读取建议不创建目录，保存路径不扫描、上传或读写应用配置。 |
| DEF-06 | 不从进程 cwd 猜测项目、不扫描整机或插件缓存；项目范围来自可信上下文或明确选择。 |

## 4. 应用结果与证据

各适配以这些编号映射自己的工具和测试，分别记录应用版本、操作系统、运行位置、验证层
及“支持 / 受限 / 不支持 / 待验证”。场景不适用时说明能力边界，不直接标为通过。
系统存储、加密通道、页面状态、实际应用及真实连接是不同验证层；mock、单元测试、
静态 SVG 或其他应用的结果不能替代目标应用完整闭环。

通用规范只保存合成场景。测试环境配置、凭据、操作脚本和运行轨迹保留在仓库外；各适配
的测试矩阵仅记录脱敏结论与未通过项，不因规范提取改变原来的验收状态。
