# 全局路线图与待办

本文只记录 agent-plugins 后续要做的功能、目标版本和依赖，所有宿主共用一份计划。
版本是插件产品的目标迭代，不是 Nacos Server 版本；各宿主包按同一功能计划适配，分别声明支持范围。
以下均为计划版本，尚未发布；接口受限的条目可以单独顺延，不阻塞无依赖的功能。

已有实现与验收记录留在各宿主目录。组合能力的设计见[多 Agent 协作规范](multi-agent-collaboration-spec.md)，
认证、更新和发布提示分别遵循对应领域 spec。沿用原 T、UI、DISC、FIX、COL 编号；字母后缀表示拆分后的独立待办。

三类提供方分别实现，不要求互相依赖；OIDC 用户身份与 OAuth2 服务身份分开配置。

| 待办 | 交付内容 | 依赖 / 完成条件 |

| T35e | 统一认证 provider 接口与安全凭据生命周期。 | 复用安全输入/存储，支持按目标及 Client/Admin 面取凭据、并发刷新、替换与清除。 |

| COL07f | 按职责定向派发与接收确认。 | COL05d、COL07a；只发送授权范围内的必要输入，记录接受、跳过、缺输入及未确认状态。 |
