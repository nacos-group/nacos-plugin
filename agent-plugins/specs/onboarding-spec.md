# 初始化与设置交接规范

本文约束 F01 的连接初始化，适用于各 Agent 应用的对话、页面或其他已验证设置入口。
连接与身份模型见[接入与治理](connection-governance-spec.md)，凭据要求见
[凭据管理](credential-management-spec.md)。连接完成后的资源扫描与托管另见
[本地资源托管](local-resource-onboarding-spec.md)，不是初始化的必经步骤。

## 1. 能力检查与执行位置

先检查插件工具及执行环境，再收集配置。未配置、工具未加载、执行位置不匹配、凭据存储
不可用是不同状态；读取到工作流说明或插件已安装不代表其运行工具已经可用。

初始化应说明文件、凭据存储和 Nacos 请求实际发生在哪台机器。本地配置必须在能访问
目标本机的执行环境完成；云端缺少本机能力时提供对应应用的本地入口指引，不自动新建
云端任务、不反复重装，也不把“无本机工具”笼统解释为“插件未安装”。

页面输入能力与系统存储能力分别检查，两者及传输通道均经过验证才可推荐页面填写。
无页面的应用仍可通过对话收集非敏感信息、使用受支持的环境变量引用完成初始化。
其他安全输入入口可由应用适配另行声明；不得要求用户将密码或 Token 发到普通聊天中。

## 2. 逐步引导

宿主提供可用的结构化问答或设置输入控件时，非敏感配置优先使用该入口，不以普通聊天
清单代替。枚举项使用单选或多选；API 地址、自定义命名空间、目录及环境变量名等自由
文本也使用原生输入或选择控件自带的自定义输入，每轮只收集一个值。没有可信候选不代表
交互入口不可用，不得虚构候选；选项可提供保留已知值、采用已核验默认值、稍后配置或取消。
用户已明确提供的信息不重复询问，也不要求先选“输入”再转到聊天填写。

仅在适用的结构化输入能力未提供或实际调用明确不可用时，才降级为一次一个非敏感文本
问题，并先说明原因；用户拒绝或取消不视为能力不可用，不得换入口绕过。能力恢复后继续
结构化交互。秘密始终通过已验证的安全入口收集，不进入普通问答或自定义文本输入。
具体控件、工具名和平台限制由应用适配声明，不把某个宿主的接口设为通用必需依赖。

1. 读取已有配置和非敏感状态，复用用户已经提供的信息，只询问缺项。
2. 确认 Nacos API 地址、命名空间和用途。展示名可选；内部连接和身份标识由适配器提供
   建议并说明用途，不要求新用户理解底层字段。通常只填一个地址；管理入口或认证不同
   时才展开独立配置，已有独立配置必须保留。
3. 询问技能安装目录和已有技能目录是否需要自定义。不需要时展示适配器给出的实际默认
   路径；已有配置优先提供“保留当前目录”。目录规则见第 5 节。
4. 选择认证方式：无需认证、支持的用户名与密码登录、访问令牌等。列表由实际能力决定；
   不根据 URL 推断无需认证，不默认使用管理员，不把某个适配未支持的 OAuth 等方式
   作为所有应用的永久限制。
5. 需要认证时单独选择凭据提供方式：具备安全能力的页面填写、环境变量引用或适配器
   明确支持的其他安全入口。不能静默改用无认证或明文文件。
6. 页面方式只预填已确认的非敏感设置，定位所选认证的输入区，提示用户自行填写并保存。
   模型不输入、读取或回显秘密，不代用户点击凭据提交。环境变量方式只收集变量名。
7. 读取保存后的配置修订与凭据状态，再继续已有授权覆盖的只读诊断。页面单独保存设置
   不自动发起网络诊断；打开表单、保存成功、诊断通过分别呈现。
8. 返回实际检查结果和下一步。消费读取成功不代表管理写权限或下游服务可用。可继续
   发现资源，也可选择本地技能盘点；扫描、上传、发布分别遵循相应授权。

环境变量必须对插件进程可见；某个终端中 `export` 成功不是运行插件已读取的证据。
应用适配提供自己的配置与刷新方式，不把重启设为所有应用必需步骤。

## 3. 对话与设置页交接

| 阶段 | 规则 |
| --- | --- |
| 打开 | 传递目标设置位置及非敏感草稿；打开和预填不修改持久配置。 |
| 编辑 | 已有未保存草稿时，提示采用新草稿或继续原编辑；不静默覆盖。 |
| 等待用户 | 页面展示当前步骤；对话只说明需要完成的输入与保存，不以固定等待时长推断完成。 |
| 保存 | 核对配置上下文及修订，拒绝覆盖其他窗口或会话已更新的配置。 |
| 返回状态 | 仅返回待输入、已保存、失败或结果未知，以及非敏感摘要、配置修订和凭据配置状态。 |
| 继续 | 保存确认后才诊断或重新生成后续操作计划；结果未知先重新读取已保存状态。 |

应用必须实际切换到对应设置位置，不能仅输出“已打开”。入口失败应说明原因并提供已验证
的替代入口；没有侧栏的应用可使用其他设置界面，不能暗中换到另一台机器或云端执行。
交接不把秘密放入普通工具参数、消息或浏览器持久存储。未保存信息的保留与清除分别遵循
[设置交互 UIX-12](resource-center-interaction-spec.md#13-uix-12-设置与返回来源)和凭据规范。

## 4. 设置与恢复状态

设置中的摘要、编辑、保存结果、检查结果属于不同状态；返回来源及页面布局由 UIX-12
统一定义。认证方式与凭据提供方式共同决定字段，只验证当前选择要求填写的内容。
修改普通字段不要求重填已保存秘密；取消、离开和切换认证时清除未提交秘密。

配置保存成功返回摘要并显示未检查；连接检查分别呈现未检查、检查中、通过、失败及时间。
结果只说明实际检查的接口。地址、身份或使用范围改变后，旧诊断、权限缓存和操作计划
按上下文规则失效；不得沿用旧身份的成功结果。失败保留非敏感输入，秘密按凭据规则清除。

## 5. 本机默认值与自定义

默认值由应用适配器在实际执行环境发现，页面与对话使用同一来源。通用层定义用途、来源
和安全约束；具体路径、环境变量名、配置语法及数量上限由应用规范定义。

| 项目 | 通用规则 |
| --- | --- |
| 安装目录 | 采用目标应用已验证可加载用户 Skill 的位置；可建议尚不存在的目录，读取建议不创建目录。 |
| 已有技能目录 | 仅将已存在、允许访问的应用目录作为扫描候选；无候选时允许为空，不阻塞连接初始化。 |
| 应用配置文件 | 适配器能定位时提供默认路径，说明后续用于何种接入操作；仅保存路径不读取或修改文件。 |
| 本地连接标识 | 用于关联本地记录；可用 hostname 生成可编辑建议，但不能把 hostname 当作全局唯一标识。 |
| 本地身份标签 | 可用当前系统用户名生成建议，用于区分本地记录；不代表 Nacos 登录账号、资源 owner 或服务端权限。 |

本地标识首次保存后必须稳定；设备名或系统用户变化不自动迁移已有记录。多连接实现需
处理标识冲突，不能仅凭同一 hostname 合并连接。系统信息不可用时提供明确的后备建议
或让用户填写，不能生成看似已核验的身份。

“使用默认值”与“保留当前值”是不同选择。已有配置、用户自定义项及主动清空的目录不因
打开设置或升级而被填回；“添加默认目录”只追加缺项、去重并保留原顺序。
路径需说明用途和有效性，拒绝越界、不可用或不安全的建议；按允许的作用域处理符号链接。
不从插件进程 cwd 猜测用户项目，不扩大到整个用户目录或插件缓存。确定项目范围需要
可信应用上下文或用户明确选择。

保存目录不触发扫描、上传或应用配置写入。实际扫描前仍需用户发起；空目录、不存在与
不可读分别呈现。相关扫描边界见[本地资源盘点](local-resource-onboarding-spec.md#3-盘点范围与来源识别)。

## 6. 适配与验收

每个应用记录执行位置检测、默认值来源、问答入口、页面打开与预填、凭据提交、配置状态
读取和诊断的具体映射。无页面时声明替代路径，不能复制侧栏文案后宣称支持。
按[通用验收场景](onboarding-acceptance-spec.md)记录应用、系统、版本与验证层级；
单个应用的通过结论不构成其他应用的支持声明。
